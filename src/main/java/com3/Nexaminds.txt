Endpoint POST /tokens que reciba JSON: cardNumber, expiryDate, cvv, requestId (UUID único del cliente).

Validaciones:

requestId ya existe → 409 Conflict ("Token ya generado")

Datos de tarjeta inválidos → 400 Bad Request

Si válido:

Genera token (simula: TKN- + UUID)

Guarda en Map en memoria: {requestId → {token, expiry, status: ACTIVE}}

Devuelve 201 con {token, expiryDate, requestId}

Seguridad: nunca loguea datos sensibles (solo *** o hashes)
